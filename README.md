# Portal Perfil 40+

Prévia do portal de conteúdo do Instituto Perfil 40+: acompanhamento de vídeos, Drive, artes, roteiros, agenda e painel do Instagram.

Os dados desta versão são de exemplo e ficam salvos só no navegador de quem usa.

## Publicar no GitHub Pages
Settings → Pages → Source: "Deploy from a branch" → Branch `main`, pasta `/ (root)` → Save.
